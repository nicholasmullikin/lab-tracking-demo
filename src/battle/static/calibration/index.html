Display only: they never alter the pixels sent to the SAM3 decoder, frames, masks, prompts, or provenance. Browser-local, not stored in calibration manifests. Order: brightness → contrast → threshold → edges → corners, drawn under the mask and prompts.

VIGRA calls VIGRA directly · NumPy has no VIGRA equivalent · partial approximates one step. VIGRA is built from source (docs/vigra-build.md); without it those cards disable themselves.

Brightness and contrast alone are applied in the browser with the same formula, so they need no round trip. Any threshold, edge, or corner aid reads the toned image, so enabling one moves the whole chain back to the server.
